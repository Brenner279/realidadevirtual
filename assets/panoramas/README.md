# Panoramas 360°

Coloque nesta pasta as fotografias panorâmicas equiretangulares dos biomas.

Nomes sugeridos:
- `amazonia-360.jpg`
- `cerrado-360.jpg`
- `caatinga-360.jpg`
- `mata-atlantica-360.jpg`
- `pantanal-360.jpg`
- `pampa-360.jpg`

Recomendações:
- Proporção 2:1 (por exemplo, 4096 × 2048).
- Preferir JPEG otimizado para reduzir o tempo de carregamento.
- Usar imagens próprias ou com licença que permita redistribuição.
- Registrar autor, origem, licença e data de acesso em um arquivo de créditos.
- Evitar imagens com pessoas identificáveis sem autorização.

O protótipo atual permite testar uma imagem 360° pelo botão **Carregar foto 360°**. A integração automática por bioma será feita quando os panoramas definitivos forem escolhidos.
