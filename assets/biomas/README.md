# Arquivos dos biomas

Cada bioma possui sua própria pasta dentro de `assets/biomas/`. As quatro imagens informativas devem permanecer diretamente na pasta correspondente, com estes nomes:

- `fauna-flora.jpg`
- `hidrografia.jpg`
- `clima.jpg`
- `vegetacao.jpg`

## Vídeo de Fauna VR

Para adicionar o vídeo imersivo de cada bioma, coloque o arquivo com o nome exato `fauna-vr.mp4` dentro da pasta do respectivo bioma:

| Bioma | Caminho do vídeo |
|---|---|
| Amazônia | `assets/biomas/amazonia/fauna-vr.mp4` |
| Cerrado | `assets/biomas/cerrado/fauna-vr.mp4` |
| Caatinga | `assets/biomas/caatinga/fauna-vr.mp4` |
| Mata Atlântica | `assets/biomas/mata-atlantica/fauna-vr.mp4` |
| Pantanal | `assets/biomas/pantanal/fauna-vr.mp4` |
| Pampa | `assets/biomas/pampa/fauna-vr.mp4` |

O botão **Fauna VR** aparece nos seis biomas. Quando o vídeo ainda não estiver na pasta, o site informa o caminho exato esperado.

O vídeo que já existia para a Amazônia foi disponibilizado também no caminho novo: `assets/biomas/amazonia/fauna-vr.mp4`.
