WASD / setas ou direcional · Olhe para uma obra
Como visitar

Computador: use W, A, S, D ou as setas para caminhar. Use o mouse para olhar ao redor.

Celular: arraste a tela para olhar e mantenha pressionado o direcional no canto inferior esquerdo para caminhar.

Aproxime-se das molduras e mantenha o olhar sobre uma obra. A iluminação e a descrição serão realçadas; quando houver vídeo disponível, ele começará automaticamente.

O botão VR aparece quando o dispositivo oferece suporte ao WebXR.
