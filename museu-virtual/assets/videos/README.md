# Vídeos das obras
Adicione aqui os cinco vídeos curtos da exposição, preferencialmente em MP4 (H.264), proporção 16:9.
Use exatamente estes nomes:
- obra-01.mp4
- obra-02.mp4
- obra-03.mp4
- obra-04.mp4
- obra-05.mp4

Os vídeos iniciam quando o visitante direciona o olhar para a área da moldura. Ao desviar o olhar, a reprodução é pausada e reiniciada na próxima visita. Para boa performance em celulares e WebXR, prefira vídeos curtos e comprimidos, com resolução de até 1080p.
